Mettre à jour l'outil

1. Copier le code

Un seul appui, rien à sélectionner.

2. Le coller dans ton projet Google
  1. Ouvre script.google.com › ton projet.
  2. + à côté de « Fichiers » › Script › nom Code2 (ou n'importe quel nom).
  3. Dans ce nouveau fichier : appui long › Coller.
  4. Sur l'ancien fichier Code.gs : ⋮ › Supprimer.
  5. Déployer › Gérer les déploiements › ✏️ › Version : Nouvelle version › Déployer.

Les liens et les données ne changent pas.
